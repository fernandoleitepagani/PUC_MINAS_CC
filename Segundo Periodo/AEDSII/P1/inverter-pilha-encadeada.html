Pilha.inverter()

Uma pilha encadeada se inverte sem criar nem mover célula nenhuma: só virando os ponteiros, um por vez. Avance passo a passo e veja onde cada variável está em cada linha.

Dentro do laço, atual.prox = anterior apaga o único caminho que sobrava até o resto da pilha. Guardar proximo antes disso é o que permite continuar andando. Abra a aba sem guardar o proximo com 3 ou 4 células: o laço encerra na primeira volta e todo o resto da pilha vira lixo para o coletor do Java.

Duas coisas que o diagrama deixa explícitas: topo continua apontando para a célula antiga durante o laço inteiro e só recebe anterior no fim; e proximo é declarada dentro do while, então deixa de existir a cada volta.

Custo: tempo O(n), memória extra O(1). Nenhuma célula nova, nenhuma cópia de dados — mudam só os n ponteiros.

o que testar

  • Pilha com 0 e com 1 célula: o método aguenta os dois sem nenhum if extra.
  • Com 1 célula, a versão bugada passa despercebida. É o argumento para testar sempre com 2 ou mais.
  • Modo desafio: prever para onde cada ponteiro vai antes de ver o passo.
  • Setas ← e → do teclado navegam os passos.
