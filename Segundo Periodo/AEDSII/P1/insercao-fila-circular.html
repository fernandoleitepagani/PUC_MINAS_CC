O algoritmo é a inserção de sempre. A diferença é que o vetor dá a volta, então todo movimento vira % tam e o teste j >= 0 vira uma posição-sentinela. Ande passo a passo e veja onde cada índice está.

Por que + tam antes do %

  
Em C o resto mantém o sinal do dividendo: -1 % 8 dá -1, não 7. Somar tam antes garante um número não negativo, aí o % leva de volta para o começo do vetor. Só aparece nas contas que recuam (primeiro - 1, i - 1, j - 1); nas que avançam, (i + 1) % tam basta.


  
Por que a posição antes de primeiro serve de parada

  
A fila reserva MAXTAM + 1 posições para guardar no máximo MAXTAM elementos — é assim que ela distingue cheia de vazia. Com a fila cheia, ultimo cai exatamente em primeiro - 1, então essa casa nunca guarda elemento. Ela é o -1 do vetor comum: um lugar seguro para o j parar.

  
E o && é curto-circuito de propósito: quando j chega na sentinela a comparação para antes de ler array[j], que ali guarda lixo.


  
Custo

  
Igual à inserção de sempre: O(n²) comparações e movimentações no pior caso (fila em ordem decrescente) e O(n) quando já está ordenada, porque o while falha na primeira comparação. Os % só somam uma constante.
